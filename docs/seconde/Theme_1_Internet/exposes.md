## Liste des sujets (1 par groupe)

### <font color="teal">1. La CNIL : rôle et missions</font>
- → Qu'est-ce que la CNIL, que fait-elle et pourquoi est-elle importante ?
- → Donner un exemple où la CNIL s'applique.

### <font color="teal">2. Le RGPD : comprendre le Règlement Général sur la Protection des Données</font>
- → Quels sont les droits qu'il garantit ? À qui s'applique-t-il ?
- → Donner un exemple où le RGPD s'applique.

### <font color="teal">3. Le droit à l'oubli numérique</font>
- → Peut-on vraiment faire disparaître ses données d'Internet ?
- → Comment faire pour bénéficier de ce droit ?

### <font color="teal">4. Les cookies et le consentement en ligne</font>
- → À quoi servent les cookies, et pourquoi doit-on les accepter ou les refuser ?

### <font color="teal">5. Quelles données personnelles les applications collectent-elles ?</font>
- → Étude de cas : une appli populaire (Snapchat, Instagram, TikTok...)

### <font color="teal">6. L'impact des réseaux sociaux sur la vie privée</font>
- → Comment les informations partagées peuvent-elles être utilisées ?
- → Donnez un exemple concret, où les réseaux sociaux ont été utilisés à mauvais escient.

### <font color="teal">7. Le cyberharcèlement et la loi</font>
- → Quelles sont les protections légales pour les victimes ?
- → Dans quel cas parle-t-on de (cyber)harcèlement ?
- → Donner un exemple de cyberharcèlement.

### <font color="teal">8. Le droit à l'image sur Internet</font>
- → Peut-on publier une photo de quelqu'un sans son accord ?
- → Quels sont les peines engendrées ?

### <font color="teal">9. Les discours de haine en ligne : que dit la loi ?</font>
- → Racisme, sexisme, homophobie : que risquent les auteurs ?
- → Qui doit-on prévenir dans le cas de discours de haine en ligne ?

### <font color="teal">10. Le droit d'auteur sur Internet : peut-on tout partager ?</font>
- → Musique, films, images : ce qu'il est interdit de faire.
- → Qui légifère les droits d'auteur en France ?

### <font color="teal">11. Les influenceurs et la loi : publicité déguisée et responsabilités</font>
- → Quelles obligations légales pour les créateurs de contenu ?
- → Donner un exemple de placement de produit qui peut poser problème.

### <font color="teal">12. Les deepfakes et les risques juridiques</font>
- → Peut-on interdire les vidéos truquées ? Quels dangers ?
- → Montrer un exemple de deepfake court.

### <font color="teal">13. L'addiction aux écrans</font>
- → Comment les applications sont-elles conçues pour capter l'attention (notifications, scroll infini) ?
- → Quels sont les signes d'une utilisation problématique et les moyens de s'en protéger ?

### <font color="teal">14. La protection du consommateur sur Internet</font>
- → Quels sont vos droits en cas d'achat en ligne (rétractation, garantie, litige) ?
- → Donner un exemple d'arnaque courante et comment la repérer.
- 
### <font color="teal">15. L'intelligence artificielle et la désinformation</font>
- → Comment l'IA peut-elle être utilisée pour créer ou diffuser de fausses informations ?
- → Quels outils permettent de vérifier une information en ligne ?
