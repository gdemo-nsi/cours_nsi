# **Progression de l'année de terminale NSI**
___

L'année sera ponctuée avec 3 projets différents : 

1. Projet Jeu de carte (avec classe)   
2. Projet RPG (avec graphe)  
3. [Les trophées NSI !](https://trophees-nsi.fr/)  

Vous aurez des exercices types bac dans la majorité des thèmes.

___

## **Thème 0 - Révisions python**
!!! note "Mots-clefs"
    - Variables
    - Listes
    - Fonctions
    - Boucles (itérations)
    > Exercices applicatifs : [fiche entrainement](../entrainement_autonomie.md)
## **Thème 1 - Structures de données avancées**
!!! note "Mots-clefs"
    - Piles et Files
    > Exercice applicatif : Tour Hanoï

## **Thème 2 - Paradigmes**
!!! note "Mots-clefs"
    - Programmation Orienté Objet (POO)
    - Paradigmes de programmation en fonction des langages
    > Exercice applicatif : Projet 1 - jeu de carte

## **Thème 3 - Sécurisation des communications**
!!! note "Mots-clefs"
    - Chiffrements symétriques / asymétrique
    - Cryptographie
    > Exercices applicatifs : Filiues, code César, XOR, RSA

## **Thème 4 - Langages et programmation avancée**
!!! note "Mots-clefs"
    - Récursivité
    - Gestion d'erreurs *(pré / post conditions, tests)*
    > Exercices applicatifs : Récursions, assert, fractale *(turtle)*

## **Thème 5 - Algorithmes sur structures**
!!! note "Mots-clefs"
    - Dictionnaires
    - Théorie des graphes
    - Parcours DFS / BFS
    - Arbres
    > Exercice applicatif : Projet 2 - RPG
  
## **Thème 6 - Bases de données relationnelles**
!!! note "Mots-clefs"
    - Modèles relationnels *(schéma)*
    - Clefs primaires / étrangères
    - SQL
    > Exercices applicatifs : Créations de playlist, word.sql
  
## **Thème 7 - Algorithmique avancée**
!!! note "Mots-clefs"
    - Diviser pour régner
    - Programmation dynamique
    - Algorithmes gloutons
    - Calculabilité, décidabilité
    > Exercices applicatifs : Rappels compréhension, Tris *(sélection, fusion, insertion)*, mémoïsation *(Boyer-Moore)*
    > Projet 3 - Trophées NSI

## **Thème 8 - Architecture matérielle et systèmes**
!!! note "Mots-clefs"
    - Processeur, mémoire
    - Ordonnancement des processus
    - Réseaux *(protocoles TCP/IP, routage, sécurité)*
    > Exercices applicatifs : Rappels binaire, table de routage, commandes bash *(ping, traceroute, chmod, etc.)*

## **Thème 9 - Préparation Baccalauréat**
!!! note "Mots-clefs"
    - Opérations sur données *(txt, csv)*
    - Recherche, modification, tri, fusion de tables
