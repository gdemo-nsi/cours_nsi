# Presentation Hebdomadaire

Au début de chaque cours de cette année, à tour de rôle vous aurez **maximum** 5 minutes pour présenter au choix :

- Un métier en lien avec l'informatique (que vous souhaitez faire par exemple, journée type),
- Un nouvelle technologique,
- Une nouvelle sur un jeu vidéo (ça peut être un jeu vidéo indépendant, où une mécanique précise).

Vous devez avoir un support.

    |Contenu de l'exposé (*points pertinants*, *exemple de situation*):|/2|
    |Respect du temps de parole :| /1|
    |Originalité du sujet (*essayer de trouver des sujets niche !*) :| /1|
